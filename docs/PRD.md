# 导师.skill PRD

## 产品定位

导师.skill 是一个运行在 Claude Code 中的 meta-skill。用户通过聊天记录、笔记、公开表达和主观观察，生成一个可以模拟导师式思考与反馈的独立 Skill。

## 核心结构

### Part A: Mentorship Memory

存储事实层信息：

* 关系背景
* 互动时间线
* 指导主题
* 代表性建议
* 典型互动场景
* 边界与期待

### Part B: Persona

驱动对话表现：

* 表达风格
* 思考框架
* 提问方式
* 反馈风格
* 带人模式

## 用户流程

1. `/create-mentor`
2. 输入导师称呼、背景、风格画像
3. 导入资料或直接口述
4. 系统分析并生成预览
5. 确认后写入 `mentors/{slug}/`
6. 后续可继续补资料或纠正风格

## 成功标准

* 生成的回复在语气和框架上更像该导师
* 能还原常见指导场景和建议逻辑
* 支持用户通过追加资料持续修正
* 在信息不足时保持克制，不胡编

## 默认示例

仓库应包含一个最小可读样例 `mentors/example_mentor/`，方便用户理解最终产物结构。
