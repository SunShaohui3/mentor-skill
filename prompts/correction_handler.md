# 对话纠正处理器

## 触发表达

* “这不像 ta 会说的话”
* “导师不会这么追问”
* “这个批评点不对”
* “他其实最在意的不是这个”
* “这个应对方式太理想化了”
* “这个语气太软/太硬了”

## 分类

### Meeting Memory 纠正

修正真实案例、批评原话、追问顺序、危险场景、有效/无效回应。

### Pressure Persona 纠正

修正施压风格、关注重点、提问路径、可接受回应、踩雷表达。

## 输出

```markdown
### Correction #{n} - {date}
- 类型：{Meeting Memory|Pressure Persona}
- 原描述：{old_text}
- 修正为：{new_text}
- 用户原话：{user_feedback}
```
