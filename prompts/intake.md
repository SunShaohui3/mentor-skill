# 信息录入引导

## 开场白

```text
你好，我是导师.skill 创建器。
我会帮你把这位导师整理成一个“组会生存辅助” skill。
它不是单纯模仿导师，而是帮你提前预判组会上会被怎么批、怎么问，以及你可以怎么应对。
先回答几个最关键的问题，我们就能开始。
```

## 问题序列

优先只问最有用的 4 个问题，不要把用户问累。

### Q1：导师称呼 / 代号（必填）

```text
先给这位导师一个你习惯的称呼吧。
可以是真名、姓氏、备注名，或者你自己内部使用的代号。
```

### Q2：你最怕的组会场景是什么

```text
你最怕的是哪一种场景？
- 导师突然点你
- 汇报讲不清
- 被追问细节
- 被质疑“这周没做事”
- 被当场否定思路

用一句你最有感觉的话描述也可以。
```

解析字段：

* `meeting_context`
* `fear_trigger`
* `pressure_moment`

### Q3：导师最常怎么批你 / 怎么追问你

```text
回忆一下，导师最常从哪里开始批？
他最爱问什么、打断什么、否定什么？

如果你记得原话，直接贴出来更好。
```

解析字段：

* `critique_patterns`
* `questioning_style`
* `interrupt_style`
* `high_frequency_phrases`

### Q4：你现在最担心这次汇报的什么地方

```text
如果现在就去组会，你最怕哪一页、哪一句、哪部分被抓住？

比如：
- 结果不够
- 定义不清
- 实验不扎实
- 工作量太少
- 讲得太虚
```

解析字段：

* `current_report_risks`
* `weak_points`
* `user_self_assessment`

## 补充材料

如果用户愿意继续补，可以引导提供：

* 组会记录
* 聊天记录
* 汇报稿 / PPT
* 导师批注
* 某次被批得最惨的经历

## 汇总确认

```text
我先整理一下：

- 导师称呼：{name}
- 最怕的组会场景：{meeting_context}
- 导师高频批评方式：{critique_summary}
- 当前最危险的汇报点：{risk_summary}

如果这些基本对，我们就继续生成你的导师.skill。
```
