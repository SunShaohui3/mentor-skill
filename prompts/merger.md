# 增量 Merge 逻辑

## 原则

1. 新信息优先追加，不覆盖已有高置信内容
2. 如果出现冲突，明确标注冲突点
3. 优先保留真实组会案例、真实原话和真实追问路径
4. 更具体的证据可以提升原结论置信度

## 合并重点

### Meeting Memory

* 新的组会案例 -> 加入“组会场景概览”或“高频批评库”
* 新的批评原话 -> 加入“高频批评库”
* 新的追问顺序 -> 加入“追问路径”
* 新的翻车点 -> 加入“汇报危险信号”
* 新的有效回应 / 无效回应 -> 加入“有效与无效应对”
* 新的恐惧触发 -> 加入“情绪触发点”

### Pressure Persona

* 新的施压证据 -> 更新“施压风格”
* 新的关注重点 -> 更新“关注焦点与提问路径”
* 新的接受/不接受回答方式 -> 更新“可接受回应”
* 新的踩雷表达 -> 更新“踩雷表达与应对建议”
